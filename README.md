# MetricTrace: Multi-Agent KPI Dispute Resolver

MetricTrace is an investigation copilot for organizations where multiple analysts independently build dashboards from the same or overlapping data sources and end up with conflicting KPI numbers — it takes a known discrepancy and produces an evidence-backed reconciliation of which differences explain the gap, how much each contributes, and what remains unresolved.
